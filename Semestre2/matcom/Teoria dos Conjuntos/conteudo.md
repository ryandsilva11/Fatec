    Transformação base 10 -> Qualquer base:

        Base 10 -> 2:

            Obs:  O último dígito é o menos significativo. 0 = par 1 = ímpar

            (147)10 = (10010001)2:
                147/2 = 73, 1
                73/2 = 36, 0
                36/2 = 18, 0
                18/2 = 9, 0
                9/2 = 4, 1
                4/2 = 2, 0
                2/2 = 1, 0

            (138)10 = (?)2:

        Base 10 -> 8:

            (147)10 = (223)8:
                147/8 = 18, 3
                18/8 = 2, 2

            (138)10 -> (?)8:

        Base 10 -> 16:

            (147)10 = (93)16:
                147/16 = 9, 3

            (138)10 = (?)16:
